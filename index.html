История игр

пусто

Каждая игра — одна строка листа: дата, счёт и три состава. Кнопка «Сохранить игру» на экране «Команды» пишет строку сама, лист нужно только создать — как это сделать, см. «Настройки» → «История: как подключить».

Шкала и скилы

Все оценки — 1–10, допускаются половинки (7.5). Если в таблице числа из FIFA (0–99), они автоматически поделятся на 10.

Поле (7)

  • Скорость — рывки, игра в отрыв
  • Удар — завершение, дальние
  • Пас — передачи, видение
  • Дриблинг — контроль, обыгрыш
  • Защита — отбор, чтение игры
  • Физика — сила, выносливость
  • Позиционирование — выбор позиции в поле, игра на опережение

Ворота (1)

  • Реакция — сейвы в упор, игра в рамке

Скилы заполняются всем — вратарём может встать любой, позиции в игре меняются. Поэтому у каждого игрока две оценки: «в поле» и «в воротах».

История: как подключить

  1. В таблице создай лист История (пустой — шапку поставит скрипт).
  2. Меню Расширения → Apps Script, вставь код ниже, сохрани.
  3. Развернуть → Новое развёртывание → тип «Веб-приложение»: «Запуск от имени» — ты, «У кого есть доступ» — все. Скопируй адрес, он кончается на /exec.
  4. Вставь адрес в поле «Адрес веб-приложения» на экране «История».
  5. Ссылку на лист «История» вставь там же — по ней приложение читает историю и статистику.
const SHEET = 'История';

function doPost(e) {
  const body = JSON.parse(e.postData.contents);
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sh = ss.getSheetByName(SHEET) || ss.insertSheet(SHEET);
    if (sh.getLastRow() === 0) {
      sh.appendRow(['ID', 'Дата', 'Команд', 'Итог', 'Синие', 'Красные', 'Белые', 'Обновлено']);
    }
    const id = String(body.id || '');
    const ids = sh.getLastRow() > 1
      ? sh.getRange(2, 1, sh.getLastRow() - 1, 1).getValues().map(function (r) { return String(r[0]); })
      : [];
    const at = ids.indexOf(id);

    if (body.action === 'delete') {
      if (at >= 0) sh.deleteRow(at + 2);
      return json({ ok: true, deleted: at >= 0 });
    }

    const row = [id, body.date || '', body.teamCount || 0, body.score || '',
      body.teams[0] || '', body.teams[1] || '', body.teams[2] || '', new Date()];

    if (at >= 0) sh.getRange(at + 2, 1, 1, row.length).setValues([row]);
    else sh.appendRow(row);
    return json({ ok: true, updated: at >= 0 });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  } finally {
    lock.releaseLock();
  }
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

Без скрипта игра всё равно сохраняется — на телефоне, с пометкой «не в таблице» и кнопкой «Отправить в таблицу».

Как заполнять таблицу

Лист, например Players. Первая строка — шапка. Нужны имя и скилы; колонка «Позиция» не требуется. Пустые скилы считаются «средними по компании».

Удалить приложение

Веб-приложение не может удалить себя само — иконку убирают через систему:

  • iPhone: удерживайте иконку «Баланс» на экране «Домой» → «Удалить приложение».
  • Android: удерживайте иконку → «Удалить» (или Chrome → ⋮ → «Управление приложениями»).
  • Компьютер: откройте chrome://apps, правый клик по «Баланс команд» → «Удалить».
